# Dynamic Island — instaladores

Widget no estilo Dynamic Island para Windows: música, relógio, notificações e atalhos no topo (ou nas laterais) da tela.

**[Baixar a versão mais recente](https://github.com/adao-locks/DynamicIsland-releases/releases/latest)** — rode o `DynamicIslandSetup-x.y.z.exe`. Não precisa de administrador.

Depois de instalada, a ilha avisa sozinha quando sai uma versão nova e se atualiza (Configurações → Atualizações).

Este repositório guarda só os instaladores; cada versão é uma [release](https://github.com/adao-locks/DynamicIsland-releases/releases).
